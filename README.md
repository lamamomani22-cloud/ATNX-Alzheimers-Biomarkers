# ATNX-Alzheimers-Biomarkers
# Alzheimer's Disease and ATN(X) Framework

This repository supports a research project investigating the role of neuroinflammatory biomarkers in the ATN(X) framework for Alzheimer's disease diagnosis.

Research Question:
Can neuroinflammatory biomarkers incorporated into the ATN(X) framework improve the diagnostic accuracy of Alzheimer's disease compared with the traditional AT(N) framework?

Key biomarkers:
- GFAP
- sTREM2
- YKL-40

The repository will be used to organize literature, notes, and project materials.
